# Automation Testing

This repository contains automation test scripts for API, UI, performance, and end-to-end testing.

## Project Contents

### API Automation

The `API Automation` folder contains automated API test scripts covering:

- GET, POST, and DELETE requests
- Request headers and cookies
- Authentication methods
- OAuth 2.0
- API chaining
- Query parameters
- JSON response parsing
- XML response parsing
- JSON schema validation
- Response status and body assertions

### Amazon UI Automation

The `Amazon.cy.js` script contains automated UI test cases for basic Amazon functionality, including:

- Opening the Amazon website
- Searching for products
- Validating search results
- Basic user interactions

### Performance Testing

The `performance-testing` folder contains JMeter test plans for performance and load testing scenarios.

## Tools and Technologies

- JavaScript
- Cypress
- Playwright
- Apache JMeter
- REST API testing
- GitHub Actions

## Prerequisites

Install the following tools before running the tests:

- Node.js
- npm
- Cypress
- Playwright
- Apache JMeter, if running performance tests
